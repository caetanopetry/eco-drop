# Marca EcoDrop

Arquivos originais fornecidos pela equipe, em PNG com transparência:

- `logo-e-nome.png` (2172 × 724): marca completa, usada pelo componente `frontend/components/brand/marca.php` nas navegações, telas de acesso e rodapé.
- `logo.png` (1254 × 1254): símbolo isolado, usado como favicon e ícone de atalho pelo componente `frontend/components/brand/favicon.php`.
- `nome.png` (2172 × 724): nome oficial, usado no destaque decorativo do rodapé.

As imagens originais são preservadas. A classe `eco-marca--clara` aplica uma versão branca por CSS para contraste em fundos escuros. O tamanho de exibição é definido por `--marca-largura`, mantendo a proporção original.

Os PNGs possuem pequenos resíduos de recorte visíveis em ampliações. Para futuras aplicações grandes ou impressas, prefira uma exportação limpa do arquivo vetorial original.
